# موقع علي & فاطمه 🤍

موقع حب ثابت (Static) على GitHub Pages — قابل للتثبيت على الموبايل (PWA). الصفحة الرئيسية React مُجمّعة في ملف واحد + صفحة لعبة المتاهة منفصلة.

**الريبو:** https://github.com/yougbhgfgi-beep/Ali-and-Fatima
**الرابط المباشر:** https://yougbhgfgi-beep.github.io/Ali-and-Fatima/

## التثبيت على الموبايل (PWA)

- **Android (Chrome):** افتح الموقع → القائمة (⋮) → **"Add to Home screen"** / "تثبيت التطبيق".
- **iPhone (Safari):** افتح الموقع → زر المشاركة أسفل (⬆️) → **"Add to Home Screen"**.
- الشرط: الموقع لازم يكون **HTTPS** (GitHub Pages زيه تمامًا).
- الأيقونة اللي بتظهر = صورة `photo-8.jpeg` (اتولّد منها الـ PNGs الجاهزة).

## المشاركة بكلام شيك

- لما تلصق **لينك الموقع** في واتساب/تيليجرام/فيسبوك — بتظهر معاينة تلقائية: العنوان `💍 علي 🤍 فاطمه 💍 — حكايتنا` + وصف مزخرف + صورة `share-cover.jpg`.
- في أسفل الصفحة فيه زرار **"شاركي قصتنا 💌"** بيفتح واتساب برسالة جاهزة مزخرفة فيها اللينك.

## أماكن التعديلات الشائعة

| عايز أعدّل | فين |
|---|---|
| **النصوص** (العناوين، المعرض، المحطات، كلمة المرور…) | `assets/index-new.js` — في الجزء `const Dt={...}` |
| **الصور / الكابشنز** | المعرض في الباندل (`gallery:[...]`) + الملفات في `images/photo-N.jpeg` |
| **أيقونة التطبيق** | استبدل `images/photo-8.jpeg` وأعد توليد الـ PNGs (192/512/maskable/apple) |
| **صورة معاينة المشاركة** | استبدل `images/share-cover.jpg` (يفضل مربع ~800×800) |
| **نص المشاركة المزخرف** | `index.html` — تاجات `og:description` / `twitter:description` |
| **الفيديوهات** | استبدل `media/video-1.mp4` / `media/video-2.mp4` (عرض جنب بعض) |
| **الأغنية** | استبدل `media/alb-wahed.mp3` بنفس الاسم |
| **كلمة السر** | الباندل: `n===\"1282026\"` + `passwordHint:\"...\"` |
| **الكاش / الأوفلاين** | `sw.js` — ولو عدّلت ملفات زوّد رقم `CACHE_NAME` (مثلاً v11 → v12) |
| **رسالة لعبة المتاهة** | `maze.html` — داخل `<div id=\"winOverlay\">` |

## ملاحظات مهمة

- **بعد أي تعديل في الباندل** (`index-new.js`): زوّد رقم الـ cache في `sw.js` عشان المستخدمين يجيبوا النسخة الجديدة.
- صور المعرض فيها `loading=\"lazy\"` عشان الموقع يفتح أسرع على الموبايل.
- لعبة المتاهة بتفتح بـ `window.open('maze.html')` من زرار اللعبة — ومحتواها كله جوه `maze.html` نفسه.
- **⚠️ صور ناقصة:** خلاص كل الـ 10 صور وصلت سليمة — المعرض كامل (photo-1..10) بكابشنزها.
